How the range is worked out
1Start with the score: p = passes ÷ runs. Here, {{hrK}} ÷ {{hrN}} = {{hrP}}. 2Decide how sure to be. We use 95%, which sets z = 1.96. 3Wilson's score interval pulls the centre a little toward 50% and sets the width from p and the number of runs n: 
centre     = (p + z²/2n) ÷ (1 + z²/n)
half-width = z × √( p(1 − p)/n + z²/4n² ) ÷ (1 + z²/n)
range      = centre − half-width  to  centre + half-width
4Why Wilson and not a flat plus-or-minus? It never runs past 0% or 100%, and it stays honest at the edges: {{hrPerfect}}
Rule of thumb: to halve the range, run about four times as many races. And the board's one rule: when two entries' ranges overlap, it calls them a tie.
