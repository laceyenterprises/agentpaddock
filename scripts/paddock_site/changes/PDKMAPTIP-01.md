# Default engine map notes

Default engine maps show the level and whose default applied, such as
“medium (OpenAI default)”. The adjacent info button explains the evidence,
including full thinking modes and why a level is not recorded. Notes open
on click, keyboard activation or fine-pointer hover; Escape dismisses them.
The garage refreshes both the label and note when a selection changes.

The published glyph set includes `info`, meaning “a note about this value”.
