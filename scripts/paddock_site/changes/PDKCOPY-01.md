# Fewer words, and lights that start the race

Reader-facing copy is shorter across the site, with the same racing terms,
counting rules and disclaimers. Driver and car examples use display names;
the garage compares cars only when a driver has placed entries in more than one.
Checkpoint descriptions say what passing means in one sentence.

The home page's five start lamps play once when they enter view, then say
“Race!” and offer “Run it again”. Reduced motion shows “Race!” straight away.
